# AC Website Design Blueprint

Design-only handoff for a premium, original Australian air-conditioning cleaning & servicing website. Reference inspected: seanmas.com.au (desktop at 1294 px; tablet/mobile emulated at 768 / 375 px). Inspection date: 7 Nov 2026.

Read in this order:

1. `06-FINAL-DESIGN-HANDOFF.md` — the brief (start here)
2. `02-DESIGN-SYSTEM.md` — tokens and component rules (source of truth for names)
3. `05-PAGE-AND-COMPONENT-ARCHITECTURE.md` — routes, components, content models, booking flow
4. `04-RESPONSIVE-BLUEPRINT.md` — breakpoint specs and QA checklist
5. `03-ANIMATIONS-AND-INTERACTIONS.md` — observed motion vs. proposed motion, with code
6. `01-DESIGN-REFERENCE-ANALYSIS.md` — section-by-section review of the reference
7. `07-REFERENCE-ASSET-INVENTORY.md` — media observed and original assets to produce

Legend used everywhere: **[Observed]** measured on the reference · **[Proposed]** our recommendation · **Not observed** absent on the reference · **Not verified** could not be inspected.

No reference copy, branding, imagery or proprietary code is reproduced in these files.
